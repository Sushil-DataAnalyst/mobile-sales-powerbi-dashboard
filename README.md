## 🎯 Business Objective

The objective of this project is to build an interactive reporting solution that helps business stakeholders quickly answer questions such as:

- How are total sales performing over time?
- How does the current period compare with the same period last year?
- Which mobile models contribute the most sales?
- Which cities generate higher sales?
- How is transaction volume distributed across months and days?
- Which payment methods are most commonly used?
- What is the distribution of customer ratings?

The dashboard is designed to move from **raw transaction data → analysis → interactive business reporting**.

---

## 📌 Key Dashboard KPIs

The dashboard provides high-level KPIs for:

- **Total Sales**
- **Total Quantity**

- **Transaction Count**

These KPIs can be dynamically explored using the available filters.

## 🚀 How to Explore the Dashboard

1. Download the `.pbix` file from the **PowerBI** folder.
2. Open it using **Microsoft Power BI Desktop**.
3. Use the slicers to filter the report.
4. Explore sales, product, customer, payment, geographic and time-based analysis.
5. Review the business insights generated from the dashboard.
